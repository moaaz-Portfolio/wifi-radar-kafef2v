WiFi Radar

مثبّت الشريحتين لبنية TX/RX مستقلة عن الراوتر. استخدم Chrome أو Edge على كمبيوتر، ووصل شريحة واحدة فقط عبر USB في كل مرة.

1 — المرسل TX أولًااحرق شريحة الإرسال الجديدة، ثم شغّلها وانتظر ظهور الشبكة.
2 — المحلل RX ثانيًااحرق الشريحة القديمة بفيرموير Analyzer RX.
3 — اللابتوباتصل بشبكة WiFi-Radar-Net ثم شغّل تطبيق Python عليها.
TRANSMITTER · TX NODE

حرق الشريحة المرسلة (Transmitter TX - الشريحة الجديدة)

تنشئ نقطة اتصال WiFi-Radar-Net وتبث heartbeat على UDP/3333 بمعدل مستهدف 100Hz. كلمة مرور الشبكة 12345678.

المتصفح لا يدعم Web Serial. استخدم Chrome أو Edge على الكمبيوتر. افتح الصفحة عبر HTTPS واسمح بالوصول إلى USB.
ANALYZER · RX NODE

حرق الشريحة المحللة (Analyzer RX - الشريحة القديمة)

تتصل تلقائيًا بنقطة TX، تلتقط CSI من BSSID الخاص بها، ثم ترسل حزم CSI1 ذات 64 قيمة إلى UDP/5005، مع استمرار حساس الباب على UDP/5006.

المتصفح لا يدعم Web Serial. استخدم Chrome أو Edge على الكمبيوتر. افتح الصفحة عبر HTTPS واسمح بالوصول إلى USB.
تنبيه RF: يستخدم الإصدار قناة 6 وعرض HT20 بدل القناة 14؛ القناة 14 يابانية ومخصصة عمليًا لـ 802.11b، ولا تتوافق مع معدل HT MCS0-SGI المطلوب. لا تغيّر بلد التشغيل إلى JP لتجاوز اللوائح المحلية. كما أن 100Hz معدل جدولة مستهدف وليس ضمانًا لصفر jitter لاسلكي.
بعد الحرق: شغّل TX أولًا. اتصل من اللابتوب بشبكة WiFi-Radar-Net وكلمة المرور 12345678. شغّل RX؛ العنوان المحلي الافتراضي لنقطة TX هو 192.168.4.1. لا توصل الشريحتين بالكمبيوتر في الوقت نفسه أثناء الحرق.
