# عقدة الإرسال TX — ESP32-S3

## بناء محلي

من بيئة ESP-IDF 5.5.6:

    cd tx_node
    idf.py set-target esp32s3
    idf.py menuconfig
    idf.py build

داخل القائمة WiFi Radar TX configuration اختر قناة نقطة الاتصال. الافتراضي 1، والقنوات الشائعة 1 أو 6 أو 11. يجب أن يتصل RX بالقناة التي يبث عليها TX.

## إعداد الشبكة والراديو

- Wi-Fi mode: SoftAP فقط.
- SSID: WiFi-Radar-Net
- كلمة المرور: 12345678
- عنوان نقطة الوصول الافتراضي: 192.168.4.1
- عرض النطاق: HT20.
- معدل الإرسال: WIFI_PHY_RATE_MCS0_SGI.
- الحد الأقصى لطاقة الإرسال: 11 dBm.
- عدد الأجهزة المتصلة: 4 (احسب ضمنها RX واللابتوب).

## معدل الإرسال والإحصائيات

مؤقت esp_timer يطلق tick كل 10,000 ميكروثانية. الـ callback يضيف رقمًا متسلسلًا إلى Queue فقط. مهمة UDP مثبتة على Core 1 ترسل الحزمة ذات 4 بايت إلى 192.168.4.255:3333. رقم التسلسل يزداد حتى لو امتلأت Queue، وبالتالي يستطيع RX تقدير الحزم المفقودة.

يسجل TX عدد الحزم ومتوسط/أقصى انحراف جدولة الإرسال وqueue drops وsocket errors كل 1000 حزمة. هذا معدل مستهدف 100Hz وليس ضمانًا لصفر jitter عبر Wi-Fi.

## الدولة والقدرة

ESP-IDF 5.5.6 لا يتضمن EG في قائمة esp_wifi_set_country_code؛ لذلك يحدد الكود wifi_country_t يدويًا برمز EG وقنوات 1..13. Espressif تحذر أن esp_wifi_set_country لا يتحقق من قواعد الدولة تلقائيًا، لذلك يجب مراجعة حدود NTRA عند أي تغيير.

الحد المحلي في مستند NTRA لنطاق Wi-Fi 2400–2483.5 MHz هو 100mW EIRP. حد 11 dBm في الراديو لا يضمن وحده EIRP؛ أضف كسب الهوائي والخسائر واحسب القدرة المشعة المكافئة قبل التشغيل.
