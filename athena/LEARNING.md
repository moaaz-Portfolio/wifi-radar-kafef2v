# التعلم العميق في Athena — النسخة v2

الهدف: نموذج يتعلم إشارة الغرفة بعمق، **ويقول «لا أعرف» بدل أن يخمّن بثقة كاذبة**.

## ما الذي تغيّر

| المحور | قبل | الآن |
|---|---|---|
| البنية | CNN + BiLSTM (طبقتان) | `ActivityNetV2`: الإشارة + مشتقتها، stem متعدد المقاييس (3/5/9)، كتل residual متسعة مع Squeeze-Excitation، BiLSTM، تجميع attention+mean+max، embedding بحجم 64 |
| الأوزان | تهيئة افتراضية | Kaiming للتفاف، Xavier للخطي، متعامد للـ LSTM مع forget-bias=1، وتهيئة آخر BN في كل كتلة بصفر (تبدأ كهوية) |
| المُحسّن | AdamW ثابت التسوس | AdamW مع **فصل التسوس** (لا تسوس على bias/Norm)، warm-up ثم cosine، قص التدرج |
| تثبيت الأوزان | أفضل epoch فقط | **EMA** للأوزان (الأكثر ثباتًا في التعميم) + اختيار الأفضل بـ macro-F1 ثم NLL + إيقاف مبكر |
| التوسيع | ربح، ضجيج، إزاحة دائرية | ربح لوغاريتمي 0.5×–2×، ميل ترددي لكل subcarrier (يحاكي اختلاف الغرف)، time-warp، إسقاط subcarriers، حجب زمني (فقد حزم)، ضجيج، mixup خفيف |
| الثقة | softmax خام (مبالغ فيها) | **Temperature scaling** على بيانات التحقق + مقاييس ECE/NLL/Brier قبل وبعد |
| عتبة الرفض | ثابتة 0.65 | تُحسب من التحقق لبلوغ دقة هدف (افتراضيًا 95%) مع حد أدنى للتغطية؛ وإن تعذّر يُذكر ذلك |
| الأشياء غير المألوفة | تُصنَّف لأقرب فئة | **NoveltyDetector** (Mahalanobis على الـ embedding): غرفة/عتاد/تشويش لم يُرَ → `uncertain` بسبب `novel_input` |
| التكيف مع بيئة جديدة | لا شيء | **RoomAdapter**: عند معايرة الغرفة الفارغة يُضبط الربح لمطابقة أرضية الضجيج التي تدرّب عليها النموذج (بلا تسميات ولا إعادة تدريب، ومحصور بين 0.33× و3×) |
| القرار الزمني | متوسط 3 إطارات | متوسط هندسي + **hysteresis** (لا يتغير القرار إلا بعد تقدّم متكرر) لمنع وميض الأحداث |
| التقرير | دقة وF1 | + فترات ثقة 95% بإعادة سحب **التسجيلات** (لا النوافذ المتداخلة)، balanced accuracy، التغطية، دقة الإجابات الفعلية، نسبة «غير معروف» |

التوافق: نقاط الحفظ القديمة (`arch` غير موجود) تُحمَّل كـ v1 دون تغيير. `metrics.json` يحتفظ بالمفاتيح السابقة، وتُضاف مفاتيح جديدة.

## حدود صريحة (لا تنبؤ مزيف)

1. **كود PyTorch لم يُشغَّل في بيئة التطوير هنا** (torch غير مثبّت ولا يوجد شبكة). المنطق الرقمي (المعايرة، كشف غير المعروف، فترات الثقة، المحوّل، hysteresis) مختبَر بـ pytest وينجح. اختبار `tests/test_torch_stack.py` يغطي النموذج والتدريب والحفظ/التحميل لكنه **يُتخطّى بدون torch**؛ شغّله أول مرة عندك: `python -m pytest tests -q`.
2. عتبة الرفض وكاشف الجِدّة تُضبطان على بيانات تحقق من نفس الغرفة، لذلك هما متفائلتان. الرقم الأصدق يأتي من `python -m athena.crossval --group room --ablate` (الآن يعرض أيضًا المعايرة ونسبة «غير معروف» في الغرفة غير المرئية).
3. RoomAdapter محاذاة من الدرجة الأولى؛ إن اختلف العتاد أو موضع الراوتر كثيرًا فالحل إعادة تسجيل/تدريب، وسيُبلغ كاشف الجِدّة بذلك.
4. لا يوجد نموذج يضمن دقة في بيئة لم يُختبر فيها. كشف السقوط يبقى مؤشرًا بحثيًا وليس جهاز سلامة.

## تشغيل

    pip install -r requirements.txt
    python -m pytest tests -q                         # الأرقام والبنية
    python -m athena --edition factory                # سجّل ثم درّب (الافتراضي arch=v2)
    python -m athena.crossval --group room --ablate   # الاختبار الأصدق (غرفة لم تُرَ)

لتدريب بنية قديمة للمقارنة استدعِ `train(..., arch="v1")`. معلمات مفيدة: `seed`, `patience`, `lr`, `weight_decay`, `ema_decay`, `mixup_prob`, `target_accuracy`.

## تنبيه للمستخدم النهائي في الواجهة

حقل `pred.reason` يقول لماذا النتيجة «غير متأكد»: `low_confidence` أو `novel_input`. وحقل `pred.novelty` درجة الغرابة (≈1 مألوف، أكبر بكثير = غريب).
